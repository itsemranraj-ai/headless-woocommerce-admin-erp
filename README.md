# 🛍️ Headless WooCommerce Admin ERP

> High-Performance Next.js 16 Administrative Portal & Order Management System for WooCommerce Stores.

## 🚀 Overview
Headless WooCommerce Admin ERP provides store owners, managers, and customer service teams with a dedicated, blazing-fast administrative portal.

- **Sub-Second Performance**: Next.js 16 + React Server Components.
- **Direct WooCommerce REST API Sync**: Clean Basic Authentication with IPv4 socket routing.
- **Mobile-First UX**: Dedicated touchscreen quantity steppers, visual showcase, and printable PDF invoices.
- **Team Access Control**: Role-based permissions without sharing main WordPress credentials.
- **WhatsApp & Email Automations**: Multi-channel notification engine.
